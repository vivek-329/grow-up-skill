📁 Git & GitHub Guide

Git is a Version Control System created by Linus Torvalds. It helps you track code changes, manage versions, and collaborate with others.

📥 Step 1: Install Git

Download Git from the official website:

Download Git

⚙ Step 2: Configure Git

After installation, open Terminal / CMD and run:

git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"

📂 Step 3: Start Your First Project

Initialize Git in your project folder:

git init
git add .
git commit -m "First commit"

🌐 Step 4: Connect to GitHub

Create a repository on GitHub, then connect it:

git remote add origin https://github.com/your-username/your-repo.git
git branch -M main
git push -u origin main

🔁 Daily Commands

git add .
git commit -m "update"
git push
